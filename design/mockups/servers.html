Join refusals, one sentence each

  • expired: This invite has expired. Ask whoever sent it for a new one.
  • revoked: This invite was withdrawn. Ask whoever sent it for a new one.
  • used: This invite has been used as many times as it allows.
  • banned: You are banned from this server.
  • member: You are already in this server. (It opens instead.)
  • full: This server is full.
  • unknown, proof, server: This invite does not work. Check that you pasted all of it.
  • busy, or nobody answers: Nobody from this server is online to let you in right now. Try again later.
